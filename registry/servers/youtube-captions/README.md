# YouTube Captions — FlashData

Retrieve YouTube uploader captions with timed segments. Prepare subtitle exports and inspect the language and caption-track type.

- [Install and run the YouTube Captions workflow](../../guides/youtube_captions.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-captions/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Captions API documentation](https://flashdata.dev/docs/sources/youtube_captions?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_captions-guide)

This server provides `youtube_captions` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
