# YouTube Captions MCP

Read an existing YouTube caption track by video ID and language. To export subtitles supplied by the uploader, set `auto` to `false`. Installation is free; each data request uses paid FlashData Credits.

[Get an API key](https://flashdata.dev/app/api-keys) · [Current pricing](https://flashdata.dev/pricing) · [API documentation](https://flashdata.dev/docs/sources/youtube_captions)

## Install

1. Install Node.js **22.18 or newer** and download the [official MCPB 0.3.0](https://github.com/flashdatadev/flashdata-mcp/releases/download/v0.4.0/flashdata-youtube-captions-0.3.0.mcpb). Expected SHA-256: `f1a50ac175b1e2725c5f6bb1169f829397734c5803347eba61e507e99b92409e`.
2. Import the bundle into an MCPB-compatible client. Enter your own key in **FlashData API Key**; it must grant `youtube_captions`. For manual stdio configuration, use the **0.3.0 bundle above** with the [manual configuration example](https://github.com/flashdatadev/flashdata-mcp/blob/main/registry/guides/youtube_captions.md).
3. List the tools. Call `get_pricing` with `{"request_count":1}` for the price of one query. Pricing, job and result reads are free.

## Example: read uploader-provided English captions

Parameters for one paid MCP `tools/call` request:

```json
{
  "name": "youtube_captions",
  "arguments": {
    "video_id": "dQw4w9WgXcQ",
    "language": "en",
    "auto": false,
    "response_format": "json"
  }
}
```

Read `results[0].segments` for `start`, `end` and `text`; times are in seconds. Check `languageCode` and `isAutoGenerated` before converting to SRT. Missing tracks are not translated, generated from audio or replaced with another track.

For chunked output, use `get_result` with `result_id` and the returned `next_offset` (as `offset`) in the same running process. Concatenate chunks in order and parse them only when `encoding` is `json`. See the [sample output](https://github.com/flashdatadev/flashdata-mcp/blob/main/registry/guides/youtube_captions.md#use-the-result).

The separate [Official MCP Registry manifest](https://github.com/flashdatadev/flashdata-mcp/blob/main/registry/servers/youtube-captions/server.json) pins the official 0.1.1 compatibility package. The examples above target the direct 0.3.0 download.
