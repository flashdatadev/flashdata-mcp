# Google Places — FlashData

Search for local businesses and places with addresses, available ratings and review counts. Build location-specific research shortlists.

- [Install and run the Google Places workflow](../../guides/google_places.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fgoogle-places/versions/latest) · [Registration manifest](server.json)
- [FlashData Google Places API documentation](https://flashdata.dev/docs/sources/google_places?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_places-guide)

This server provides `google_places` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
