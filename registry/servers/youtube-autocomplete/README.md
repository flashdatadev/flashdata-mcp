# YouTube Autocomplete — FlashData

Get YouTube search suggestions for a query prefix, language and region. Build keyword idea sheets from actual autocomplete phrases.

- [Install and run the YouTube Autocomplete workflow](../../guides/youtube_suggestions.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-autocomplete/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Autocomplete API documentation](https://flashdata.dev/docs/sources/youtube_suggestions?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_suggestions-guide)

This server provides `youtube_suggestions` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
