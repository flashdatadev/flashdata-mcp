# Google Images — FlashData

Find Google Images results with image URLs, dimensions and original source pages. Build an attributable image research inventory.

- [Install and run the Google Images workflow](../../guides/google_images.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fgoogle-images/versions/latest) · [Registration manifest](server.json)
- [FlashData Google Images API documentation](https://flashdata.dev/docs/sources/google_images?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_images-guide)

This server provides `google_images` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
