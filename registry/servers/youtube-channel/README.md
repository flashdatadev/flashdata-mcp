# YouTube Channel Data — FlashData

Read a YouTube channel profile and recent videos by handle. Capture channel identifiers and a bounded recent-upload inventory.

- [Install and run the YouTube Channel Data workflow](../../guides/youtube_channel.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-channel/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Channel Data API documentation](https://flashdata.dev/docs/sources/youtube_channel?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_channel-guide)

This server provides `youtube_channel` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
