# Google Search — FlashData

Search Google for ranked web pages, titles, URLs and snippets. Build localized SERP snapshots for research and comparison.

- [Install and run the Google Search workflow](../../guides/google_search.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fgoogle-search/versions/latest) · [Registration manifest](server.json)
- [FlashData Google Search API documentation](https://flashdata.dev/docs/sources/google_search?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_search-guide)

This server provides `google_search` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
