# Google News — FlashData

Search Google News for articles, publishers, date labels and source links. Turn a topic into a traceable news briefing.

- [Install and run the Google News workflow](../../guides/google_news.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fgoogle-news/versions/latest) · [Registration manifest](server.json)
- [FlashData Google News API documentation](https://flashdata.dev/docs/sources/google_news?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_news-guide)

This server provides `google_news` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
