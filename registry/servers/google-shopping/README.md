# Google Shopping — FlashData

Search Google Shopping for products, merchants and price labels. Collect comparable offer snapshots with product IDs and source links.

- [Install and run the Google Shopping workflow](../../guides/google_shopping.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fgoogle-shopping/versions/latest) · [Registration manifest](server.json)
- [FlashData Google Shopping API documentation](https://flashdata.dev/docs/sources/google_shopping?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=google_shopping-guide)

This server provides `google_shopping` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
