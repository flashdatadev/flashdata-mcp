# YouTube Metadata — FlashData

Read YouTube video details, descriptions, statistics and available chapters. Inspect formats or prepare timestamped chapter navigation.

- [Install and run the YouTube Metadata workflow](../../guides/youtube_metadata.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-metadata/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Metadata API documentation](https://flashdata.dev/docs/sources/youtube_metadata?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_metadata-guide)

This server provides `youtube_metadata` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
