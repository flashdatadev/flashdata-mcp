# YouTube Search — FlashData

Search YouTube videos by keyword with date, duration, feature and sorting filters. Return video IDs, channels and available statistics.

- [Install and run the YouTube Search workflow](../../guides/youtube_search.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-search/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Search API documentation](https://flashdata.dev/docs/sources/youtube_search?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_search-guide)

This server provides `youtube_search` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
