# YouTube License Metadata — FlashData

Inspect a YouTube video’s Creative Commons license classification. Record the returned license-label signal for a separate rights review.

- [Install and run the YouTube License Metadata workflow](../../guides/youtube_trainability.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-trainability/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube License Metadata API documentation](https://flashdata.dev/docs/sources/youtube_trainability?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_trainability-guide)

This server provides `youtube_trainability` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
