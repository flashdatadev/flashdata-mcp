# YouTube Download to Cloud Storage — FlashData

Deliver YouTube video, audio or clips to your own S3 or other supported cloud storage. Track asynchronous delivery and its output manifest.

- [Install and run the YouTube Download to Cloud Storage workflow](../../guides/youtube_download.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-download/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Download to Cloud Storage API documentation](https://flashdata.dev/docs/sources/youtube_download?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_download-guide)

This server provides `youtube_download` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
