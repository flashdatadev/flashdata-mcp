# YouTube Extended Search — FlashData

Search larger YouTube video result sets, with up to 700 requested results. Map recurring channels and topics from structured video records.

- [Install and run the YouTube Extended Search workflow](../../guides/youtube_search_extended.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-extended-search/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Extended Search API documentation](https://flashdata.dev/docs/sources/youtube_search_extended?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_search_extended-guide)

This server provides `youtube_search_extended` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
