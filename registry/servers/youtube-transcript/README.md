# YouTube Transcript MCP

Read a YouTube transcript by video ID and language. By default, `auto: true` selects an existing automatically generated caption track; the tool does not transcribe audio. Installation is free; each data request uses paid FlashData Credits.

[Get an API key](https://flashdata.dev/app/api-keys) · [Current pricing](https://flashdata.dev/pricing) · [API documentation](https://flashdata.dev/docs/sources/youtube_transcript)

## Install

1. Install Node.js **22.18 or newer** and download the [official MCPB 0.3.0](https://github.com/flashdatadev/flashdata-mcp/releases/download/v0.4.0/flashdata-youtube-transcript-0.3.0.mcpb). Expected SHA-256: `5d94df509edb2d0bf605b82c3d99c140fab8b54c9ceb229bee9d37422c0d6eb1`.
2. Import the bundle into an MCPB-compatible client. Enter your own key in **FlashData API Key**; it must grant `youtube_transcript`. For manual stdio configuration, use the **0.3.0 bundle above** with the [manual configuration example](https://github.com/flashdatadev/flashdata-mcp/blob/main/registry/guides/youtube_transcript.md).
3. List the tools. Call `get_pricing` with `{"request_count":1}` for the price of one query. Pricing, job and result reads are free.

## Example: retrieve timestamped English text

Parameters for one paid MCP `tools/call` request:

```json
{
  "name": "youtube_transcript",
  "arguments": {
    "video_id": "dQw4w9WgXcQ",
    "language": "en",
    "auto": true,
    "response_format": "json"
  }
}
```

Read `results[0].segments`. Pair each `text` with `start` and `end` in seconds so readers can check a quotation in the video. `languageCode` and `isAutoGenerated` identify the track. A missing track is not translated or replaced by uploader captions.

For chunked output, use `get_result` with `result_id` and the returned `next_offset` (as `offset`) in the same running process. Concatenate chunks in order and parse them only when `encoding` is `json`. See the [sample output](https://github.com/flashdatadev/flashdata-mcp/blob/main/registry/guides/youtube_transcript.md#use-the-result).

The separate [Official MCP Registry manifest](https://github.com/flashdatadev/flashdata-mcp/blob/main/registry/servers/youtube-transcript/server.json) pins the official 0.1.1 compatibility package. The examples above target the direct 0.3.0 download.
