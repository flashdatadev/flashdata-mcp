# YouTube Transcript — FlashData

Retrieve available YouTube transcript text with start and end timestamps. Build cited summaries, searchable notes and transcript exports.

- [Install and run the YouTube Transcript workflow](../../guides/youtube_transcript.md): inputs, output example, costs and limits.
- [Official Registry record](https://registry.modelcontextprotocol.io/v0.1/servers/io.github.flashdata-dev%2Fyoutube-transcript/versions/latest) · [Registration manifest](server.json)
- [FlashData YouTube Transcript API documentation](https://flashdata.dev/docs/sources/youtube_transcript?utm_source=official-mcp-registry&utm_medium=integration&utm_campaign=intent_gtm_2026q4&utm_content=youtube_transcript-guide)

This server provides `youtube_transcript` plus pricing, job and result reads restricted to that source. It runs locally via the linked MCPB package with Node.js 22.18+ and your own API Key. The software is free; FlashData data calls are paid. Registry publication and natural-language search visibility are verified separately.
