# Load timestamped automatic captions for RAG

Bring an existing automatic caption track into a retrieval collection. Each segment becomes a Document with its available start/end time, language and video URL so your application can cite the passage. Inspect transcript quality before relying on it.

## Setup and run

Install the package from the [public source instructions](../README.md). PyPI publication is pending. Get your API Key from the [FlashData console](https://flashdata.dev/console) and configure `FLASHDATA_API_KEY` in your application's secret manager. Python 3.11+ is required.

[Runnable example](../examples/youtube_transcript.py): `python examples/youtube_transcript.py`.

The example makes one paid request, retains the complete raw response, and converts it locally without a second request. The reader alternative below makes its own single request; choose one approach.

```python
from llama_index.tools.flashdata import FlashDataReader

reader = FlashDataReader(source="youtube_transcript")
documents = reader.load_data(**{"video_id": "dQw4w9WgXcQ", "language": "en", "auto": True})
for document in documents:
    print(document.metadata, document.text)
```

## Input and output

- Input: video_id; language (default en); auto (default true).
- API output: results[]: videoId, languageCode, isAutoGenerated, segments, fullText; usage.credits.
- Reader output: LlamaIndex Documents; tool output: ToolOutput with the complete response in raw_output.
- Contract and current parameters: [YouTube Transcript API documentation](https://flashdata.dev/docs/sources/youtube_transcript).

## Cost, limits and errors

The package is free to install. FlashData API calls use paid Credits; see [pricing](https://flashdata.dev/pricing). Model, embedding and customer-storage charges are separate. Reads an existing track. No ASR, translation, or automatic fallback to uploader captions.

There is no automatic retry. On a timeout or ambiguous submission, inspect FlashData Jobs before paying for another request. This example does not call a model or embedding service. Inspect external content before passing it into an agent.

This guide is source documentation for an independent integration, not evidence of an official LlamaHub listing.
