# FlashData MCP servers for Cline

Choose the independent data capability your AI agent needs. Each guide contains the complete installation command, Cline configuration, example input, result-handling steps, cost disclosure and limits. The 15 servers reuse the existing fixed-source Docker targets; there is no new hosted service or authentication flow.

Docker is required. Build from the pinned public source, then configure your own FlashData API key. Installation is MIT/free; API data calls consume paid FlashData Credits. Client/model and storage costs are separate. Marketplace acceptance and public listing are separate from these direct installation instructions.
